# Padma-Kalika (पद्म-कलिका) | Steroid-Free Ayurvedic Fungal & Itch Relief

Updated static storefront website ready for instant deployment or local preview.

## Included Files
- `index.html` — Self-contained storefront (`Padma-Kalika (पद्म-कलिका) | Steroid-Free Ayurvedic Fungal & Itch Relief`) with embedded visuals, interactive 3D Lotus-Bud Airless Vessel (`Three.js`), 4-Step Cure Ritual, AI Skin Triage, Cure Kits, and Bag/Checkout drawer.
- `vercel.json` — Clean URL configuration for Vercel static hosting.

## How to Run
- **Direct Open:** Double-click `index.html` in any browser.
- **Local Server:** Run `python3 -m http.server 8080` inside this folder and open `http://localhost:8080`.
- **Deploy (Vercel / Netlify / Cloudflare Pages / GitHub Pages):** Replace the old folder contents with these files and deploy—no `npm install` or build step required.
